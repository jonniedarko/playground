DX300 stepper

Drive a four-signal stepper motor sequence with one MC6000 and a DX300 digital I/O expander.

On this page
  • The brief
  • Parts allowed
  • Inputs and outputs
  • What a correct circuit must do

The brief#

From the DX300 datasheet:

The reference circuit controls a stepper motor using the DX300 to drive the motor-0, motor-1 and motor-2 signals, with the microcontroller's own simple I/O pin p0 driving the remaining motor-3 signal.

The DX300 itself packs three separate on/off lines into one XBus value's digits - the datasheet's own usage section is explicit about which:

When representing the state of the simple I/O pins, the value in the ones column corresponds to p0, the tens column to p1, and the hundreds column to p2.

So driving motor-2, motor-1 and motor-0 together over the DX300 means writing one three-digit XBus value each time step, not three separate writes.

Inputs and outputs#

This puzzle takes no input terminal - the sequence is generated by the program alone. All four outputs are simple I/O.

What a correct circuit must do#

Four time units, then the pattern repeats. Every cell below is exact - a single MC6000 talking to a passive DX300 has no cross-chip handshake to leave uncertain.

motor-0 never moves in this design - the ones digit of every value the DX300 is written is 0.
