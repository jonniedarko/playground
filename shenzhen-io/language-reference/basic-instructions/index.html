Basic instructions

nop, mov, jmp, slp and slx.

On this page
  • nop
  • mov
  • jmp
  • slp
  • slx

nop#

nop

This instruction has no effect.

mov#

mov R/I R

Copy the value of the first operand into the second operand.

mov 100 p1     # drive simple I/O pin p1 high
mov x0 acc     # read an XBus packet into acc
mov acc dat    # copy between registers

jmp#

jmp L

Jump to the instruction following the specified label.

loop:
  mov 100 p1
  jmp loop

slp#

slp R/I

Sleep for the number of time units specified by the operand. A sleeping microcontroller consumes no power.

See Application Note 393 for why sleeping - rather than looping - is the right way to wait for the next time unit.

slx#

slx P

Sleep until data is available to be read on the XBus pin specified by the operand.

slx only accepts an XBus pin. It is the idiomatic way to wait on an XBus producer without burning power in a polling loop.

  slx x0         # wait for a packet
  mov x0 acc     # then read it
