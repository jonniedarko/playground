SHENZHEN I/O

The MCxxxx programming manual, parts datasheets and application notes, transcribed from the in-game binder.

On this page
  • The five tabs
  • Where to start

SHENZHEN I/O ships with a manual meant to be printed and put in a three-ring binder: a language reference for the MCxxxx microcontroller family, datasheets for every part you can drop on a circuit board, application notes from 诚尚Micro, and a pile of supplemental documents that turn up as puzzle specifications.

These pages are a transcription of that binder, reorganised for reading on a screen. The section layout follows the original tab dividers.

The five tabs#

The printed binder is divided into five tabbed sections:

  1. Application Notes - short design guides from the chip vendor.
  2. Language Reference - the MCxxxx instruction set and program model.
  3. Parts Datasheets - one sheet per component.
  4. Supplemental Data - the documents individual puzzles hand you.
  5. Engineering Notes - blank paper. Bring your own.

Where to start#

New to it? Read the quick start. It is one page: six facts, the two pin types, and three programs you can type straight in.

Mid-puzzle and need one instruction? The reference card is the fastest lookup.

Want to try something? The workbench is a live board - place parts, wire them up, write a program and run it here in the page.

Want the full detail? Start at Program structure.

Note

Everything here describes the fictional MCxxxx family from the game SHENZHEN I/O by Zachtronics. It is a transcription of the game's own manual, kept for reference while playing.
