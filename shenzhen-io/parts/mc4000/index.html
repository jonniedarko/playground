MC4000

High performance microcontroller: 9 lines of program memory, one register, four pins.

On this page
  • Description
  • Features
  • Pin configuration
  • Registers
  • MC4000X variant

诚尚Micro - document CSM_TD_1000198

Description#

A reduced-functionality microcontroller to help lower BOM costs, the MC4000 is a flexible and versatile alternative to its larger cousin, the MC6000. Don't let its diminutive size fool you, however: the MC4000 can easily hold its own with its generous nine lines of program memory, one general-purpose register, and four I/O pins.

Features#

  • (9) lines of program memory
  • (1) general-purpose register
  • (2) XBus pins
  • (2) simple I/O pins

Note

At any given time, a simple I/O pin is either in input mode or output mode. Writing a value to a pin register will put the corresponding pin into output mode with the specified output value. Reading a value from a pin register will put the corresponding pin into input mode, clearing any previously set output value.

MC4000X variant#

As a result of customer feedback, an XBus-only variant is available under the MC4000X part number. It carries the same nine lines of program memory and single register, but all four pins are XBus (x0-x3) with no simple I/O.
