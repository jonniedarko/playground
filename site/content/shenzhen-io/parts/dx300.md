## Description

Control the world with the DX300 digital I/O expander. This unique and useful
part can read or write up to three on/off signals at once over simple I/O or
XBus.

## Usage

- **Write** a 3-digit number to any XBus pin to change the state of the simple
  I/O pins. The three digits of the value written will be used to turn the
  simple I/O pins on (`100`) or off (`0`) depending on whether the digit is a
  `1` or a `0`.
- **Read** from any XBus pin to get a 3-digit number that captures the state of
  the simple I/O pins. The digits of the resulting XBus value will be set to
  either a `1` or a `0` depending on whether the simple I/O pin is on (`100`) or
  off (`0`).
- When representing the state of the simple I/O pins, the value in the **ones**
  column corresponds to `p0`, the **tens** column to `p1`, and the **hundreds**
  column to `p2`.

## Example table

| XBus value | `p0` | `p1` | `p2` |
| --- | --- | --- | --- |
| 100 | 0 | 0 | 100 |
| 011 | 100 | 100 | 0 |
| 000 | 0 | 0 | 0 |

> [!NOTE]
> At any given time, the DX300 is either in input mode or output mode. Writing
> an XBus value to the DX300 will put its simple I/O pins into output mode with
> the specified output values. Reading an XBus value from the DX300 will put its
> pins into input mode, clearing any previously set output values.

## Example circuit: stepper motor controller

The reference circuit controls a stepper motor using the DX300 to drive the
`motor-0`, `motor-1` and `motor-2` signals, with the microcontroller's own
simple I/O pin `p0` driving the remaining `motor-3` signal.

> [!TIP]
> Because the DX300 packs three lines into the digits of one value, the
> [`dgt` and `dst` instructions](/shenzhen-io/language-reference/arithmetic-instructions/)
> are the natural way to build and pick apart the values you send it.
